# Prompt Assets Reference

This packaged copy keeps the installed `prompt-assets` skill usable after
`skill-installer` copies only this directory.

In the source repository, the canonical source lives at
docs/prompts/prompt-assets.md.

## Prompt Assets

Prompt assets are versioned prompt units that should be reviewed and referenced
explicitly.

## Required Traits

- versioned
- named
- tied to a task
- explicit about variables
