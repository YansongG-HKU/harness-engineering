# Eval Design Reference

This packaged copy keeps the installed `eval-design` skill usable after
`skill-installer` copies only this directory.

In the source repository, the canonical source lives at
docs/evals/eval-design.md.

## Eval Design

Eval design starts with explicit success criteria and should be trace-aware when
output-only judgment is insufficient.

## Eval Questions

- what counts as success criteria
- what cases must be covered
- what failures traces should expose
